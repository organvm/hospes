# Governance

HOSPES is an ORGANVM-maintained open-source project.

## Decision model

Maintainers use lazy consensus for reversible changes. Consequential changes to authority,
privacy, schemas, persistence, external adapters, or the draft-only safety line require an issue,
tests, and explicit maintainer review. The repository owner is the final decision-maker when
consensus cannot be reached.

## Maintainer responsibilities

Maintainers keep `main` releasable, review contributions fairly, preserve compatibility where
reasonable, document security boundaries, and publish material breaking changes. Maintainer access
is granted or removed by the repository owner based on sustained, trusted participation.

## Scope boundary

The open repository contains code, schemas, documentation, and synthetic fixtures. Live guest,
contact, correspondence, credential, contract, media, and operator data remain in separately
controlled runtime custody and are not governed as project content.
