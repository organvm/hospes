# Security and privacy

Please report vulnerabilities and privacy concerns privately through the repository's Security
tab or directly to the repository owner. Do not open a public issue containing credentials,
contact details, correspondence, unpublished source material, exploit details, or production data.

Include the affected version or commit, impact, a minimal reproduction using synthetic data, and
any known mitigations. The maintainer will acknowledge a complete report, assess severity, and
coordinate remediation and disclosure. No fixed response SLA is promised.

HOSPES stores operator and guest data outside Git. Repository fixtures must be synthetic.
Correspondence generation is draft-only; delivery requires a separate, explicit human approval
boundary. See `docs/OPEN_SOURCE_BOUNDARY.md` for the public/private data contract.
