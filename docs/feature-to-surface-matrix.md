## Legend

- **Specified**: documented in completion registry / completion conditions
- **Written**: implementation modules, handlers, templates, or schemas exist
- **Registered**: completion registry entry exists and references a predicate
- **Reachable**: operator/API/CLI surface is wired to call path
- **End-to-end executable**: data can flow through API + storage + surface
- **Demo-ready**: runnable in synthetic demo or clearly marked non-authoritative specimen
- **Production-ready**: predicate can pass on live data with no synthetic guard
